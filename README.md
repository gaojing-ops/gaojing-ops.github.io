# 五人远征 · KEYSTONE

个人 GitHub Pages 首页：https://gaojing-ops.github.io/

五人自动秘境游戏，选择队伍、刷本、收集装备并挑战更高钥石。页面 `/` 与 `/games/keystone/` 使用同一套入口和脚本，旧长夜余烬文件已从当前版本移除。历史版本仍可从 Git 历史中恢复。

无需构建，直接静态托管。运行 `python -m http.server 9876`。代码与测试说明见 [游戏说明](games/keystone/README.md)。地图来源、处理方式与数据边界见 [地图资料](games/keystone/maps/README.md)。
