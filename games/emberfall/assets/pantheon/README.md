# 余烬诸神图册

`eight-gods-v1.png` 是一张 4 × 2 的八神神像图册（1774 × 887），由内置 imagegen 工具生成，原图保留在 Codex generated_images。项目通过 CSS 背景定位分别使用八幅神像，未裁切、重绘或铺到战斗地图上。

顺序：上排烛照、乘岚、震霄、凝月；下排青萝、玄瞳、余铸、曦衡。图片用于首页祈誓卡、诸神图鉴及暂停/结算的神明头像。

配套图标由 `flux/src/NightMagic.js` 使用原生 Canvas 绘制：8 枚神印与 9 枚角色技能印，保持现有切面图标语言。角色技能与神赐特效也在该模块绘制，逻辑与画面分离，不消耗战斗随机数。
