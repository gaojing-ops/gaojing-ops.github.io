# 长夜余烬 · EMBERFALL

一款使用原生 JavaScript 与 Canvas 2D 制作的俯视角生存肉鸽小游戏。选择角色，在荒野中走位、自动攻击、收集经验，并通过随机三选一升级组合自己的流派。生存时间达到 180 秒会召唤最终 Boss；击败 Boss 才能通关。

## 运行

游戏位于网站的 `games/emberfall/` 目录，无需安装依赖或构建。GitHub Pages 可直接托管。

本地调试时，在仓库根目录启动一个静态文件服务器，例如：

```sh
python -m http.server 8000
```

随后访问 `http://localhost:8000/games/emberfall/`。请通过 HTTP 访问；不要直接以 `file://` 打开 HTML，因为游戏使用浏览器 ES 模块。

## 操作

| 功能 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 按住画面空白处拖动，摇杆跟随落点 |
| 攻击 | 自动瞄准与攻击 | 自动瞄准与攻击 |
| 冲刺 | 空格 | 冲刺按钮 |
| 暂停 / 继续 | P / Esc 或暂停按钮 | 暂停 / 继续按钮 |
| 选择升级 | 点击卡牌或数字 1 / 2 / 3 | 点击卡牌 |

## 文件

- `index.html`：游戏界面和弹窗结构。
- `styles.css`：响应式布局、颜色、动效和触屏控件。
- `game.js`：战斗、移动、敌人、升级、渲染和音效。
- `app.js`：界面与引擎连接、角色选择、触屏交互和本地战绩。

所有游戏美术均由 Canvas / SVG 绘制，无外部图片、字体或运行时依赖。音效在用户操作后由浏览器生成。游戏为单人本地运行，战绩保存在当前浏览器，不在设备之间同步。

开发说明见 [DEVELOPMENT.md](../../docs/DEVELOPMENT.md)，包含状态流转、键盘事件、结算边界及回归测试方法。

## 神明赐福

炎神强化伤害和灼烧，风神提升移速并缩短闪避冷却，雷神强化暴击，霜神减速敌人并增加护甲，森神提高生命和恢复。升级时选择一项赐福，可混合搭配；图鉴与本次构筑显示神明来源。人物脚下的闪避条显示剩余冷却和就绪状态。

战斗区域上方常驻已获得的赐福名称和等级，横向滑动可查看更多；点击“详情”可暂停查看完整效果。无需再滚动到页面底部。
