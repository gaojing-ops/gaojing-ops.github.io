# 五人远征 · 三部位装备与 DIY 路线

首页 `/` 与 `/games/keystone/` 共用相同入口。无依赖静态应用，运行 `python -m http.server 9877`。

## 本版玩法

- 19 个专精，1 坦克、1 治疗、3 输出。普攻、技能、治疗、嘲讽、打断与敌人攻击遵守独立射程；读条移动暂停，危险区域优先躲避。
- 坦克带路、队友沿走廊跟随；落后成员沿导航图追赶。战斗位置有避让、追击范围和站位稳定规则。职业图标随网站打包，点击队员查看射程、行为、目标与冷却。
- 武器、护甲、饰品三个部位；六种自动触发饰品。一键穿装保护已选饰品效果。掉落匹配当前队伍职责，连续两次无数值升级后提供当前层数可获得的升级保底。
- 八本默认路线，统一 8 分钟限时、12 分钟结束，死亡罚时 5 秒，团灭等待 6 秒、三次团灭结束。首版关闭词缀叠加。
- 红玉路线默认只需选择“稳妥推进 / 适度合拉 / 积极合拉”，点击“使用这条路线”即可；自动安排怪群、进度、爆发与打断。地图预览折叠显示，原有逐组选择、排序、合并与打断设置放在“高级自定义（可选）”。已有自定义路线保留，进行中切换打法只调整后续波次。需要 100% 敌方进度与全部三位首领；已击杀实例不重复贡献进度，额外引怪参与实际战斗。
- 编辑路线会自动暂停；进行中远征只允许修改当前波次之后的内容。其余七本暂时使用默认波次。
- 结算记录每波耗时、额外引怪、漏断、危险区域命中、死亡来源、有效/过量治疗、承伤、超距时间和有效行动时间。

## 数据与数值

`rules.js` 集中控制层数成长（生命每层 8%、伤害每层 6%）、装备每档约 6%、品质最高 5% 差距、急速/暴击上限、群攻前五全额/后五 30%。四首领副本按 0.86 血量预算归一，红玉按完整实例数使用独立小怪血量预算；并非复制正式服战斗数值。

红玉 MDT 原始 Lua 保留在 vendor，`python scripts/build-ruby-data.py` 生成怪物实例与进度数据。导航采用基于现有地图路线的人工走廊图与怪群支路，不是正式服完整碰撞网格。危险技能和首领机制仍为休闲改编，源技能 ID 可以在怪群详情中查看；不声称还原正式服全部技能。

Raider.IO 是赛季地图、原始时限和一条阵容的静态资料参考，不参与运行时请求，也不用于职业排名。

## 存档

存储键保持 `keystone-idle-v1`，档案及战斗格式升级为 3。首次迁移前备份到 `keystone-idle-before-v3`；写入失败不覆盖原档，并停止自动写入。

旧头/胸/鞋转换为护甲并选最高档穿戴，多余件进入无容量上限的迁移收纳区，只能领取或分解。保留队伍、层数、历史和收藏；旧历史标记为旧规则，旧进行中远征需重开。新版检查点包含路线、击杀实例、进度、读条、随机数、导航和 AI 状态，恢复后暂停。

## 统一验证

- `node --test tests/keystone.test.mjs tests/maps.test.mjs tests/route-presets.test.mjs`
- `node scripts/balance-keystone.mjs`：每本 100 个固定种子、五个层数与两档装备，并覆盖所有可替换专精，输出根目录 `balance-report.json`。
- 浏览器：红玉自定义合并路线完整通关、队员详情、路线编辑、装备穿戴、暂停与续玩；390px 视口检查页面和弹窗无横向溢出。手机真机触控仍需实机验收。

素材来源、许可和地图边界见 maps/README.md 与 vendor/NOTICE.txt。

最终验收：29 项回归通过；914 场模拟，其中八本各 100 个初始装备种子全部通关，完成时间中位数为 323—406 秒。全部坦克与治疗在 +2/+5 基准通关。高层默认路线存在超时，尚非长期平衡结论。浏览器自定义合并路线 6:12 通关，无控制台错误；390px 检查通过，手机真机待验收。

路线简化验收：35 项回归通过，三种预设均实际模拟通关；浏览器验证预设保存、重新打开后的选中状态、高级配置展开/收起及 390px 无横向溢出。
