# 五人远征试作版

独立入口 `/games/keystone/`。正式首页与长夜余烬保持原样。无依赖，无构建步骤。

开发完成后再集中测试；本版实现：19 个职业专精选项、固定 1 坦 1 治疗 3 输出；自动路线、仇恨/嘲讽、治疗/专属技能、打断与地面躲避；8 个赛季地图名、各 12 组遭遇和 3 名自定义首领；+2 至 +20 层、死亡惩罚、团灭复活、强韧/暴君/涌动的简化机制；装备掉落、职业匹配、五部位、手动与全队推荐穿戴；本地存档和刷新恢复、失焦暂停、有限背包与连续刷本、战斗贡献和历史记录。

地图名称参考国服官方公告 https://wow.blizzard.cn/news/24294369/index.html （2026-10-30 核对）。路线、首领名字与数值均为原创简化，游戏不是正式服副本攻略。

运行：仓库根目录 `python -m http.server 9875`，打开 `/games/keystone/`。

玩法：选队伍和副本，开始后不需要操作。连续刷本只在页面可见时运行，失败、背包不足、打开弹窗或失焦时取消待续局。主动勾选后可再次启动；不是后台挂机或离线收益。装备进度使用独立 key `keystone-idle-v1`，不接触长夜余烬存档。

验收：开发整版完成后统一测试。18 项新测试覆盖八本真实默认队伍通关、全部 19 专精、仇恨/打断/治疗/躲避、高层失败、死亡惩罚、刷新恢复的精确随机数/仇恨/技能状态、装备转移与提升、奖励去重、背包限制、存储失败、Raider.IO 快照映射和示例阵容。原游戏 8 项回归通过。浏览器实际完成两局，确认结算掉落、解锁层数、一键穿戴（生命和强度上升）、刷新恢复、阵容示例和 390px 手机宽度。控制台无错误。尚未进行手机真机和长时间连续挂机测试。

验证命令：`node --test tests/keystone.test.mjs tests/game.test.mjs`。

Raider.IO 参考：`raider-reference.js` 保存公开 API 的八本时限和一条国服 +24 阵容快照。游戏时限=正式服公开时限/10；数值不直接复制正式服。脚本 `python scripts/update-keystone-reference.py` 可手动刷新。仅保存专精/角色分工和副本元数据，不保存玩家账号、登录信息或受限路线。参考阵容按钮不代表榜单统计排名。
