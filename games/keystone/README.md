# 五人远征

GitHub Pages 首页 `/` 与 `/games/keystone/` 使用相同入口，全部脚本与资源位于 `games/keystone/`。旧“长夜余烬”项目及专属测试、说明已从当前版本移除。Git 历史保留。

无依赖、无构建，运行 `python -m http.server 9876` 即可游玩。

## 地图与玩法

八本采用游戏内副本地图图集与真实首领位置，参考固定版本 Mythic Dungeon Tools 数据。首领场次数量与副本匹配；每本使用各自区域路线与走廊转折。可以在“查看全图”和“跟随队伍”间切换。来源及许可详见 [地图说明](maps/README.md)。地图坐标来源、图集拼接脚本和游戏路线均随公开仓库提供。

队伍为 1 坦、1 治疗、3 输出，共 19 个专精选项；自动行进、拉怪、仇恨/嘲讽、治疗、技能、打断与地面避让。限时通关提升钥石，死亡惩罚、团灭复活和词缀采用简化数值。装备有五个部位和职业匹配，可手动或推荐穿戴，保存背包、战斗记录与队伍配置。

Raider.IO 公开接口提供赛季地图、原始时限与一条国服 +24 阵容示例（不代表职业排名）。游戏时限缩短为原时限十分之一；`raider-reference.js` 是静态快照，运行时不依赖外部 API。可用 `python scripts/update-keystone-reference.py` 手动刷新。

## 存档兼容

保留本机装备、队伍、背包和历史。地图路线升级为存档版本 2，无法将旧蛇形路线的进行中远征映射到新地图，恢复时提示重新出发；不会清除装备或历史。离开页面自动暂停，进行中战斗每 3 秒及 pagehide 时保存。连续刷本仅在当前页面可见时运行；失败、背包不足或打开弹窗后不会继续排下一局。

## 验证

开发结束后统一运行 `node --test tests/keystone.test.mjs tests/maps.test.mjs`，验证八本完整通关、动态首领数、独立路线、走廊路径、往返存档、装备效果及首页切换。浏览器验证首页、旧路径、地图全览/跟随、手机宽度、真实完整通关及装备穿戴。验收结果在测试完成后补入。

本次验收结果：22 项自动化测试通过，涵盖八本新路线限时通关、真实首领数量与坐标、图集唯一性、首页一致性、旧项目移除、龙骑转场/存档以及全部原有装备与结算逻辑。浏览器已确认实际底图、全图/跟随切换与无控制台错误；手机真机仍待用户实机体验。
