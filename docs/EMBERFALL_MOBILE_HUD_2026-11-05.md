# 手机战斗遮挡修复 · 2026-11-05

本轮优先处理手机截图中血条、章节、祈誓面板及大连杀文字盖住角色的问题。

- 手机血条面板由 118 逻辑像素压到 60，保留角色名、生命数值、血条、经验条、阶位和击败数。
- 连杀数字并入顶部状态栏，手机不再绘制中央的大号连杀和断连提示。护甲、余烬及完整记录仍可在暂停页查看。
- 章节压到 24 像素；祈誓、状态提示合并为一行，超长省略。成就、际遇及首领入场改为左下角短提示，避开右侧技能按钮。
- 手机战斗、升级和暂停期间收起站点标题、导航及页尾；结束远征后恢复。保留画布暂停按钮及网页全屏入口。
- 修正隐藏标题实测高度为零却仍预留旧标题高度的问题，尺寸变化继续更新相机和输入映射。
