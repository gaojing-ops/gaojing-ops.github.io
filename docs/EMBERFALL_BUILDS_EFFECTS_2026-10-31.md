# 长夜余烬：构筑、觉醒融合与后期特效复查

本轮吸收原 gecao 开发经过中关于流派深度、数值说明、重复命中开销及大面积特效遮挡的经验。保持正常五章二十分钟、现有暗林庭院、切面美术和暖金网页界面；原微信项目不改动。逐局与性能数据见 [原始记录](../reports/emberfall-builds-effects-2026-10-31.json)。

## 发现与修正

- 觉醒后的主武器曾被直接跳过，导致后续融合消失；同时，尚未完成试炼的融合会遮住普通觉醒。现在两条路线分别判定，已觉醒主武器也能融合。执行奖励时再次核对武器、等级、材料和试炼，阻止失效选项或重复消耗。
- 融合后清除旧觉醒伤害/冷却倍率及旧武器领域，使用融合定义本身的数值；消耗副武器、释放武器格后立即重算共鸣。失去荆毒三件共鸣时不再残留毒层传染，独立的传染护符效果保留。
- 首领试炼和首领成就曾读取登场波次，现统计真正完成死亡结算的首领数，每位只计一次，新局清零。
- 星纱法师的协同加成曾只乘在未被使用的返回值上，现直接进入七种反应的实际伤害或灼伤。霜烬迸裂、月影凝霜、寒荆裂响补上原说明对应的主目标伤害；月影凝霜延长冻结至多 3.6 秒，不缩短已有更长冻结。被冻结敌人的荆毒和灼伤照常跳伤，灼伤计入伤害统计。
- 图鉴新增「流派与融合」，暂停新增「流派之途」：21 条觉醒、6 条融合，展示材料、当前/最高等级、实际试炼进度和就绪状态；已完成路线显示材料已炼成。另可展开五系两/三件共鸣和七种异系触发条件。升级卡提示正在接近的路线、可形成的共鸣和协同；融合卡明确吸收哪件副武器以及共鸣将重新计算。
- 补齐引力场、蚀骨萤群、守夜灯阵、融合近身领域的绘制，按实际作用半径显示。大型弹丸、黑洞与融合领域改为作用边界和小型施法纹样，减少旧觉醒光晕叠加；屏外友方领域不绘制，每帧至多三个友方场地带填色。简约档减少装饰，保留判定边界。
- 两类融合用来展示范围的弹体不再进入伤害、暴击、状态和协同碰撞流程。伤害继续由其真实技能逻辑负责，避免每帧对大批目标重复扫描。对象池重置展示标记。
- 手动选择精细/简约后关闭自动调档并保存；「自动光影」可单独重新开启，避免设置在下一帧被自动覆盖。

## 验证与边界

全仓 187 项自动检查通过。最后的巨大弹丸绘制和已完成配方文案修改后，40 项相关检查再次通过。包含全部六条「普通觉醒 → 融合」路线、条件不足/重复操作、真实首领计数、七种协同实际血量变化、持续伤害、共鸣移除、领域半径、填色预算、画质保存与绘制不消耗战斗随机数。

桌面浏览器分别实际操作六种融合馈赠、消费副武器和暂停行装；材料/试炼由明确标记、不写存档的本地模拟页预设，不算六次自然成型长局。另在实际 390 像素窗口检查路线搜索、共鸣/协同展开、升级融合卡、融合后暂停路线，无面板横向溢出或无效字段；不是手机真机触控认证。

四组普通引擎模拟均为中等誓印、无誓途/旅伴/灯纹，固定种子 37，60 Hz，正常助手与随机奖励，无无敌或强制局内装备。星纱法师/凝月、毒枝术士/烛照完成 20:00；霜语者/青萝在 14:22 阵亡，守灯人/乘岚在 02:13 阵亡。失败原样保留，小样本不代表总体胜率，也不强行把随机构筑调整为必胜。模拟运行后的变化只有首领成就判据、画质设置和绘制/引导，战斗数值未再调整。

另一次正常速度浏览器实跑使用独立临时中等成长档：生命/伤害誓印各 5、移速 4、拾取/冷却/恢复各 3、熟练 2、重抽 1，无誓途/旅伴/灯纹；星纱法师祈誓凝月，开启双助手，正常随机奖励，无强制装备或加速。自然完成五章 **20:00 胜利**，第 **323** 阶、击败 **81,314**、实际造成伤害 **113,542,018.7**、恢复 **3,797.8**，自然得到「霜腐幽潭」融合。结算与控制台截图/文本已保存，无警告或错误。该局不代表零成长结果；运行中最后一批绘制与设置调整未热替换进该页。

性能对照使用同一固定压力夹具：180 个耐久冻结/中毒目标，每次真实施放两种融合，随后测量一次碰撞，重复 50 次，施放耗时不计。基线 `476a043` 的碰撞查询 150 次、展示弹体进入协同 18,000 次，碰撞 CPU 中位 13.14 ms；修改后分别为 50 次、0 次、中位 0.073 ms。该结果只证明这一重复碰撞路径被消除，不能换算成整局帧率提升。

最终绘制在 1280×900 浏览器、180 敌影的静态快照中采样 120 帧：六融合精细档 CPU 中位/P95 11.7/14.9 ms；领域与毒萤精细档 9.6/12.0 ms，简约档 8.9/11.2 ms。快照停止战斗更新，只测绘制调用，不含完整战斗/GPU合成成本，不保证低端设备 60 FPS。首轮截图因夹具未启动独立绘制而为空，已修正后重新截图和采样；空图不作为验收依据。浏览器正常长局的绘制版本早于最终透明度与纹样收敛，其结果只验证正常战斗流程。
