# 最新版零成长与中等成长复查

本轮从 `bb83b99` 的已发布版本开始，使用正常速度、五章二十分钟模式、正常界面选角/祈誓与双助手，在独立临时存档中实跑。不开无敌，不强发武器、材料或试炼计数，不加速、不跳章。测试页只记录正常运行的数据，不改正式浏览器存档；临时页与模块不发布。

零成长没有誓印、誓途、旅伴或灯纹。中成长只设置誓印：生命 5、伤害 5、移速 4、拾取 3、冷却 3、恢复 3、熟练 2、重掷 1；誓途、旅伴和灯纹仍为空。这两个档位与上一轮成熟成长样本分开。

## 修复

- **重复的觉醒材料误导选项和助手**：已经持有护符，或对应武器已经觉醒时，不再给后续护符等级标“解锁进化”或额外增加 15 点权重。第一次取得真正缺少的材料仍有协同提示。实测原零成长霜语者在 02:00 战败，武器四级而觉醒护符已重复升级；修复后的另一局在 01:17 自然觉醒，但该随机对照不能当作普遍胜率。
- **灯阵起手打不到首领**：随行绕行距离读取实际灯阵半径，在保留首领身体间距的前提下进入攻击范围；宽范围后期仍用正常距离，低血和明显危险优先避险。回归实际推进移动与武器更新，确认伤害发生且不穿过首领身体。
- **静止/缓慢地雷被当作离弹忽略**：附近速度不超过 50 像素/秒的危险弹体使用径向避让，包含完全重合的情况；快速远离的弹体仍不会触发无效躲避。
- **紧急预警只会步行**：步行来不及退出地面预警时，随行可以使用已就绪的普通闪避。受减速而无法及时跑出时，接近爆炸再利用原有闪避无敌窗口；不绕过冷却，不覆盖手动移动，也不在步行可撤离时消耗闪避。暂停说明同步补充这一行为。发现依据是零成长霜语者 14:27 满血受到范围爆炸而战败，记录保留。

这些修改没有更改武器伤害、首领数值、怪物刷新、预警半径/伤害/时长或普通闪避的冷却和无敌时间。

## 版本与结果口径

运行中的标签页不热替换。基线、中间候选和最终代码的结果分别记录；中途主动停止的基线不计作死亡或通关。普通觉醒、自然融合和神龛重铸分别核对，融合以实际武器 ID 与素材位消耗为准，不根据事件名称中的 `evolution` 推断。

最终代码包按 LF 统一换行后的 SHA256 为 `6e7d9bcc199bb8e9ef532ad9393ae3cc92c9af1fd1e3e1dedbfc5871830645da`。全部 200 项检查通过，新增覆盖真实随缘选择、灯阵实际伤害/安全间距、静止地雷、减速预警闪避与冷却/手动输入优先。

逐局结算、自然觉醒/融合前后行装、逐分钟成长、受击和阶段 CPU 统计见 [数据报告](../reports/emberfall-zero-mid-release-2026-11-01.json)。完整桶计数、截图和失败验收保留在本地 `outputs`；报告保留聚合统计，不重复完整直方图。

## 后期视野与性能范围

本轮长局使用上一轮最终发布的主角标记、敌弹上层、细拖尾、地面填色预算、屏外掉落裁剪和真实 CPU 成本自动光影。阶段采样分别记录更新与绘制的 CPU 用时，使用 0.5 ms 桶；多个标签页同时运行会影响负载，不能换算为单游戏 GPU 帧率或低端设备承诺。自然失败样本不作为后期性能样本，也不强补材料以宣称融合成功。

神龛重铸是正常随机事件：霜语者中间局在约 04:34 将已觉醒冰晶换为普通满级火箭，旧倍率不再残留，之后正常重新觉醒。本轮没有把随机换掉强武器本身当作错误。毒枝术士事件中的 `evolution_plasma_arc` 是普通觉醒，已通过实际行装核对，不能算融合。

最终版中成长霜语者的自然融合由逐分钟行装和暂停完成态确认。采样器只捕获两种普通觉醒选项类型，没有捕获 `union` 选择的准确瞬间；因此融合时间使用最后一个未融合快照至第一个已融合观察的区间，不编造秒级时间。

该局在 08:00.39 仍持有冰晶与毒雾，08:30.40 观察到两件素材合为 `fusion_cryo_toxic`，并正常腾出武器位。08:53 的暂停「流派之途」显示「寒毒结界 · 已成型」「腐枝吐息已被吸收」，冻结击败为 2,050/30。14:22 的「锋芒记录」显示该融合直接累计伤害 328,044，对最近首领「腐根母巢」伤害 3,231；毒素持续伤害独立归因，不能只凭这一直接伤害占比判断控制领域的全部价值。
