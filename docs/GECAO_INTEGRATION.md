# gecao 原玩法融入长夜余烬

本次按作者要求复用小程序原规则，默认网页不再采用三分钟压缩方案。原微信项目未改动。

## 来源与结构

`flux/src/` 是本次提供的 FluxMusou / gecao wx 源码快照，共 62 个 CommonJS 模块。`flux/source-manifest.json` 保存导入时每个源文件的 SHA-256；52 个源模块保持字节一致；其余修改限定在标题/选角、地图/角色/怪物/首领绘制、显示名称及场景前后排序。`gameplay-baseline.json` 记录原角色/章节/首领定义与原敌人、首领、章节行为方法摘要，测试确认美术接线未改变这些玩法。测试核对这些哈希。

`flux/entry.js` 从项目 `game.js.map` 内嵌的可读入口提取，保留原场景注册和回调；浏览器画布、渲染循环由 `flux/browser.mjs` 接管。未发布微信项目配置、AppID、私有配置、Git 元数据、node_modules 或调试工具。

`build-gecao.mjs` 解析所有相对 CommonJS 引用，生成静态函数表与缓存，保留循环引用行为。不使用 eval、不从网络拉取运行时依赖。

## 保留的原规则

- 正常模式 5 章 × 240 秒 = 1200 秒；章间三选一奖励，最终章通关，之后可进入无尽。
- 当前实际目录：34 武器、26 被动、9 角色、35 普通怪物类型、10 Boss 定义。每把普通武器最高 6 级。
- 实际武器伤害：`floor(baseDamage × (1 + level × 0.33) × might × evolutionMultiplier)`；冷却受原 CDR 和进化影响，CDR 上限 90%，实际发射间隔下限 0.1 秒。
- 普通敌人血量倍率 `25^(分钟/20)`，伤害倍率 `12^(分钟/20)`。Boss 使用其原有独立倍率。没有采用交接文档中旧的 2000 倍血量说明。
- 进化保留原武器满级、对应被动以及击杀/治疗/元素击杀等解锁条件，进化核心可按原规则解锁。
- 保留原元素协同、角色技能、事件、诅咒、天赋、芯片、遗物、宠物、Build、每日挑战、首领连战、速通、无尽与自动走位/自动升级。

## 浏览器适配

- 手机逻辑画布 390 × 844；桌面随页面使用宽屏画布，上限宽 1280。DPR 最大 2；缩放/全屏同步画布和鼠标/触摸逻辑坐标。
- 保持主移动指针，第二指针可释放闪避或技能；取消指针仅清理，不触发点击确认。
- WASD/方向键、空格、E、P/Esc；可访问的菜单与强化按钮。
- 暂停、失焦、后台、新手引导期间不推进战斗时间或技能冷却；返回页面手动继续。
- 独立浏览器存储前缀，写入失败时提示并暂存内存。旧试炼战绩和五人远征数据保持分离。
- 图片路径以 `flux/` 模块目录解析，保留源路径布局。地图恢复第一版程序绘制的庭院与独立树石，扩展世界分块林地，按角色脚底位置排序并淡化遮挡；地表图集不再预载或使用。
- 保留重新设计的角色、普通怪物与首领图集（见 [美术说明](ART_REDESIGN.md)）及浏览器程序化音效；原项目音频目录仅有空占位，未发布这些占位文件。
- 微信好友/全服排行 API 不伪造，沿用原场景的不可用提示。局外数据不与微信或其他设备同步，不提供进行中战斗的跨刷新恢复。

## 验证

自动化覆盖源文件一致性、武器公式/冷却上限、进化条件与核心、所有角色初始武器、全部武器更新与绘制、五章奖励/最终结算、实际战斗更新、网页暂停/失焦/后台/引导冻结、存储隔离与失败降级、指针缩放和取消。

浏览器检查：标题、选角、诅咒选择、新手引导、开局、键盘移动/闪避/技能、暂停冻结、装备/伤害入口与控制台。五章边界使用引擎测试推进验证；不把它当作人工完整打通 20 分钟或手机真机多指验收。

原三分钟试炼继续保留其回归测试和 `/games/emberfall/trial.html`。五人远征不更改玩法。

## 网页营地首页

首页恢复原暗林庭院、暖金按钮与「当世界沉入黑暗」「你，是最后的火光」「在围猎中生存，在余烬中成长」文案。时间说明按二十分钟更新，不沿用小程序标题菜单。

`flux/camp.mjs` 负责网页首页选角、模式与附加试炼。角色图片共用新图集；背景仅复用旧试炼的 ready 绘制，开局后销毁。开局通过原角色与诅咒场景回调，保留原属性、解锁条件和玩法，不显示独立选角页。首页已有操作提示，因此首次开始不再展示小程序触屏引导卡。

自动化覆盖首页选角到原开局回调、已锁定诅咒过滤、首领与速通模式标记。浏览器确认首页选铁卫后直接进入 150 生命的战斗，并可正常暂停。
