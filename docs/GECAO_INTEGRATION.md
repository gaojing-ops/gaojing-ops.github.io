# gecao 原玩法融入长夜余烬

本次按作者要求复用小程序原规则，默认网页不再采用三分钟压缩方案。原微信项目未改动。

## 来源与结构

`flux/src/` 保留本次提供的 FluxMusou / gecao wx 源码快照及后续修复，共 62 个原始 CommonJS 模块。`flux/source-manifest.json` 保存导入时每个源文件的 SHA-256；当前 28 个原始模块保持字节一致，其余 34 个包含网页显示适配及后续实机发现的战斗修复，新增模块另计。`gameplay-baseline.json` 保留原定义和方法摘要作为对照；未变的方法继续核对哈希，接触伤害、毒素上限、死亡幂等、结算和升级预览等修复另有行为回归测试，不把原快照等同于当前全部行为。

`flux/entry.js` 从项目 `game.js.map` 内嵌的可读入口提取，保留原场景注册和回调；浏览器画布、渲染循环由 `flux/browser.mjs` 接管。未发布微信项目配置、AppID、私有配置、Git 元数据、node_modules 或调试工具。

`build-gecao.mjs` 解析所有相对 CommonJS 引用，生成静态函数表与缓存，保留循环引用行为。不使用 eval、不从网络拉取运行时依赖。

## 保留的原规则

- 正常模式 5 章 × 240 秒 = 1200 秒；章间三选一奖励，最终章通关，之后可进入无尽。
- 当前实际目录：34 武器、26 被动、9 角色、35 普通怪物类型、10 Boss 定义。每把普通武器通过常规强化最高 6 级；章间「所有武器 +1 级」仍保留原规则，可额外突破至 8 级。
- 实际武器伤害：`floor(baseDamage × (1 + level × 0.33) × might × evolutionMultiplier)`；冷却受原 CDR 和进化影响，CDR 上限 90%，实际发射间隔下限 0.1 秒。
- 普通敌人血量倍率 `25^(分钟/20)`，伤害倍率 `12^(分钟/20)`。Boss 使用其原有独立倍率。没有采用交接文档中旧的 2000 倍血量说明。
- 进化保留原武器满级、对应被动以及击杀/治疗/元素击杀等解锁条件，进化核心可按原规则解锁。
- 保留原元素协同、角色技能、事件、诅咒、天赋、芯片、遗物、宠物、Build、每日挑战、首领连战、速通、无尽与自动走位/自动升级。

## 浏览器适配

- 手机逻辑画布宽 390，高度按可用窗口适配（最高 844）；桌面随页面使用宽屏画布，上限宽 1280，矮窗口同步压缩高度。DPR 最大 2；缩放/全屏同步画布和鼠标/触摸逻辑坐标。
- 保持主移动指针，第二指针可释放闪避或技能；取消指针仅清理，不触发点击确认。
- WASD/方向键、空格、E、P/Esc；可访问的菜单与强化按钮。
- 手动暂停与新手引导期间不推进战斗时间或技能冷却。未同时开启随行走位和随缘强化时，失焦/后台仍自动暂停；双开时按下述挂机规则继续。
- 独立浏览器存储前缀，写入失败时提示并暂存内存。旧试炼战绩和五人远征数据保持分离。
- 图片路径以 `flux/` 模块目录解析，保留源路径布局。地图恢复第一版程序绘制的庭院与独立树石，扩展世界分块林地，按角色脚底位置排序并淡化遮挡；地表图集不再预载或使用。
- 保留重新设计的角色、普通怪物与首领图集（见 [美术说明](ART_REDESIGN.md)）及浏览器程序化音效；原项目音频目录仅有空占位，未发布这些占位文件。
- 网页旧卷只展示本机战绩，不显示尚未接入的微信好友/全服排行。局外数据不与微信或其他设备同步，不提供进行中战斗的跨刷新恢复。

## 双开辅助后的切屏挂机

同时开启「随行走位」和「随缘强化」，并点击继续守夜后，窗口失焦不再触发暂停；失焦窗口及隐藏标签页均使用独立后台计时更新原战斗。仅在标签页真正隐藏（`document.hidden`）时跳过 Canvas 重绘，分屏失焦但仍可见的窗口继续正常渲染画面。未双开、手动暂停、引导、结算或离开网页时仍停止相应推进；返回前台不会擅自解除手动暂停。

后台计时按实际经过时间拆成最多 1/60 秒的原引擎更新步，每批最多 120 步，单次后台累积上限限制为 5 秒（`MAX_CATCHUP_SEC = 5`），并在批量追帧期间通过 `SFX.withBatchMute` 静音，防止长时间挂机切回时主线程卡死或音频节点爆炸。前后台共用时钟，切回时包含最后一段后台时间且不重复计算。切屏会释放键盘与触屏输入；关闭/刷新不提供离线战斗。

117 项自动化测试通过，覆盖双开/单开、无动画帧后台推进、最后一段后台时间、限流后的分步处理、长时后台追帧上限与批量静音、失焦可见窗口正常绘制、手动暂停与页面销毁。
