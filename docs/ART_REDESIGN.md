# 长夜余烬统一美术

当前默认风格以第一版庭院为准：俯视角、简洁切面、苔绿与旧铜、克制的暖金灯火。角色、敌人、场景、技能表现和 UI 使用同一套材质与造型规则。

## 当前实现

- `flux/src/WorldScenery.js` 保留第一版石环庭院、树林、岩石、石柱与火盆，世界坐标、分块林地和前后遮挡保持不变。
- `flux/src/FacetedArt.js` 统一绘制 9 名守夜者、35 种普通敌人、10 名首领。每类有独立轮廓、配色或器具；头像与实战使用同一模型。
- 角色以斗篷、兜帽、旧铁甲、弓杖与提灯区分；怪物用骨兵、幽魂、虫兽、树根、巨像等轮廓区分；首领保留多首兽、裂隙、冠冕和鹿角等特征。
- 武器、护符、遗物、誓印与技能按钮共用原生图标。补给、符灯与三种旅伴一并使用切面绘制。
- 投射物改为烛火、骨刃、冰棘与咒石等几何形状；火池与毒沼使用半透明切面，并保留实际半径的轮廓。分身与冰轮复用相同角色/冰晶风格。粒子改为克制的碎屑与火星。
- `flux.css` 与 `flux/folio.css` 使用切角石板、旧铜细边、深绿底色与暖金交互状态，覆盖主页、图鉴、成长、强化、奖励、暂停与结算。
- `flux/theme.mjs` 将实战状态栏、章节条、闪避与咏誓控件接到同一图标与材质系统。

模型以 Canvas 原生图形绘制并缓存，运行时不加载外部图片图集。动画最多两帧，负坐标不会增加额外帧缓存；首领缓存分辨率高于普通怪物，供高 DPR 和较大尺寸使用。绘制不修改实体数据、不读取战斗随机数。

## 配套规则

1. 形体以清晰剪影和两到三个色面表达，不叠写实纹理或金属高光。
2. 角色、头像、图标与场景使用同类切面、阴影与苔绿/旧铜/骨白颜色。
3. UI 以石板和刻纹表达层次；暖金表示选择与可操作状态，不使用霓虹描边。
4. 敌方预警和效果范围保持可辨认，装饰不能改变实际碰撞或技能半径。
5. 所有数值、伤害公式、AI、章节时长、购买费用、解锁条件和存档字段由原引擎管理。

## 归档素材

早期 imagegen 图片方案继续保留在 `flux/art/`，原提示词见 [ART_PROMPTS.md](ART_PROMPTS.md)，便于回溯；当前默认角色、敌人、首领、头像与地表均不使用这些 PNG。`atlas-layout.json` 和 `ArtLayout.js` 也是该方案的归档元数据。

## 验证

自动化覆盖全部角色/敌人/首领映射、轮廓区分、头像与实战共用模型、不加载旧图集、绘制不消费战斗随机数、缓存帧上限、特效/旅伴/符灯不改实体数据，以及原公式与章节行为。网页界面与战斗仍有桌面、手机及原场景回调的集成检查。未将这些检查等同于人工打通二十分钟或手机真机压力测试。
