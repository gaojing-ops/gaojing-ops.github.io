# 长夜余烬 · 暗林奇幻美术

本轮使用内置 imagegen 重新设计图片，原样保存生成文件，未使用脚本绘制或修图。完整提示词见 [ART_PROMPTS.md](ART_PROMPTS.md)。

## 图片清单

- `games/emberfall/flux/art/heroes.png`：九名角色，真实透明背景。战斗角色和选角头像共用一份图集。
- `games/emberfall/flux/art/monsters.png`：6×6 图集，覆盖源码全部 35 种普通怪物；额外一格为森林精英造型。真实透明背景。
- `games/emberfall/flux/art/bosses.png`：十名首领，真实透明背景。保留攻击预警、血条及状态覆盖层。
- `games/emberfall/flux/art/terrain.png`：3×2 地表图集，五章地表与一格营地备用地表。
- `games/emberfall/flux/art/atlas-layout.json`：按透明像素间隙检查后的源矩形坐标。运行时直接从原图集取矩形，不裁切或改写 PNG。

## 视觉与接线

风格为俯视角手绘奇幻，使用苔绿、旧铜、暖金、骨白与克制的冰蓝/紫色。五章依次呈现灰烬林地、腐根沼泽、霜裂遗迹、虚渊墓境、黎明圣城。显示名称改变，原章节 ID 与每章 240 秒保持不变。

`flux/src/Art.js` 管理本地图集预载、矩形取样、朝向镜像、轻微运动与受击提亮。地表使用镜像重复以缓解纹理边缘接缝，并降低亮度；玩家脚下有暖色定位圈。怪物身体替换为图片，原有精英/护盾/状态提示继续绘制。仅图片显示与显示名称改变，碰撞半径、伤害、敌人 AI、章节奖励和进化数值不变。

图片在初始化时预载，失败则回退原绘制。原小程序的旧图片保留在源码快照中，当前默认渲染使用新图集。

## 验证边界

自动化检查 PNG 尺寸/透明通道、所有取样矩形不越界、九名角色与 35 种普通怪物、十个首领的图片映射、五章不同地表，以及原玩法定义/行为方法没有变化。浏览器检查选角头像与实际战斗地表/角色，控制台无错误。没有声称完成手机真机压力测试或人工全程打通二十分钟。
