# 自然构筑长局与后期视野复查

本轮用四个独立浏览器临时档，正常速度进行五章二十分钟远征。角色、神明及双助手从正常界面选择，没有强制局内武器、试炼计数、奖励、无敌或跳章。局外档案沿用此前正常购买验证过的七类满级相关誓印和完整生存誓途；无旅伴/灯纹。该条件用于观察成熟构筑与后期负载，不代表零成长。逐分钟状态、觉醒/融合前后行装和 CPU 采样见 [原始记录](../reports/emberfall-natural-builds-2026-11-01.json)。

## 发现与修复

- **神龛重铸残留旧力量**：实跑观察到神龛改变武器，追查发现旧实现只改 ID、定义和觉醒标记，没有清除旧觉醒倍率、领域/分身/毒萤，也没重算共鸣。改为全新普通武器实例替换原槽位，保留满级规则并立即重算共鸣。七种隐藏独立觉醒定义排除出普通武器池。神龛改用暖金符印，取消旧加色光圈。
- **首领伤害榜遮挡**：实际画面里，五秒大榜挡在战场中央，计时依赖绘制次数，低频绘制/后台会延长遮挡。桌面改为右侧两项简报，窄屏战斗不弹大榜；完整最近首领记录保留在暂停「锋芒记录」。计时由战斗更新推进，手动暂停仍冻结。记录复制原始数值，首领对象复用不会改写它，新局清空。
- **多件觉醒武器叠加遮挡**：狂刃融合后的实跑仍有过大的实心火刃、冰轮和粗拖尾。较大弹丸的实心纹样使用 18 像素基准尺寸，真实碰撞半径用细边界表达；取消重复旧光晕和 1.3 倍显示膨胀，拖尾至多 4 像素并减淡。增加主角定位小标记，敌弹绘制移到友方特效之上。伤害、数量、冷却和碰撞半径保留。
- **固定步进误导自动画质**：旧控制器把固定模拟步长当作帧耗时，无法感知实际绘制压力。网页每次可见战斗绘制后采样一次实际更新/绘制 CPU 用时，每 60 次样本调整一次：平均超过 25 ms 降档，低于 12 ms 缓慢恢复，中间区间保持。后台追时及标签页间隔不作为绘制负载，手动画质仍优先。
- **后期屏外掉落仍全量绘制**：实跑结算时已有 600–850 件持久掉落。现在像经验结晶一样裁剪屏外掉落的绘制，保留全部奖励及其正常更新/拾取，不通过清空奖励减负。回归覆盖 800 件屏外掉落不进入绘制。

## 验证边界

四局在同一电脑的独立标签页运行，运行中的版本不热替换。前三局使用 `ace0cfc` 的战斗/绘制；毒枝术士一局包含新的真实帧成本采样。神龛修复、最终特效收敛、掉落裁剪与首领简报在发现问题后完成，另用明确标记的重建画面和回归检查验证，不能称为四局都在最终发布版上重新打通。

自然融合与普通觉醒、神龛重铸分别记录。未配对成功的局如实保留，不补发材料。最终全仓 **196 项**检查通过；包括神龛替换后的真实伤害/冷却/共鸣、隐藏定义过滤、无绘制时通知到期、记录拷贝与新局清除、真实 CPU 采样和后台排除，以及真实范围/实心尺寸/拖尾、敌弹层级与屏外奖励保留。390 像素窗口下，完整首领记录面板客户宽和滚动宽均为 349，无横向溢出。

自然局 CPU 统计使用 0.5 ms 桶记录 JavaScript 更新/绘制调用，多个游戏与对照页同时运行影响负载，不能换算为单游戏 FPS。静态画面按实跑狂刃行装重建，固定种子、六武器、五轮发射和 180 个耐久敌人，停止战斗更新，只用于视野/绘制验证。首轮夹具因绘制发生在浏览器清屏之前而为空，修正顺序后重新验收，不将空画面作为证据。

临时测试页/模块在结束后删除，不发布；截图、原始日志和失败验收保留在工作区 `outputs`。正式用户存档不改动。
